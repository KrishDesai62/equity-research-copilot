# Model and research-agent connection — October 24, 2026

Deployed in the company **Combined research** tab on Ledger.

The same issuer and evidence cutoff are used for:
- existing growth and risk evidence agents;
- focused liquidity, funding and debt evidence retrieval;
- the checksum-pinned, release-gated bankruptcy-disclosure model service.

A combined assessment links dated financial inputs to related source passages in
four topics: liquidity, debt, profitability and growth. Every topic link points to
a cited passage displayed in the report. These topic links are not feature
importance, causal explanations, or evidence that the model is correct.

Only a production-approved, finite score can appear in the combined model signal.
An operating threshold is additionally required for a screening signal. Research
scores are withheld from this assessment. Every report abstains on buy/sell calls.
Missing sources, missing inputs and release gaps are explicit.

Optional AI synthesis receives the same gated model context and cited sources;
no provider is currently configured, so this uses deterministic organization and
extractive agent evidence rather than an AI-generated interpretation.
